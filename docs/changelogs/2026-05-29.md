# Changelog — 2026-05-29

## Added

- `Logs/` folder with indexed session logs (`.txt`, `.md`, `.jsonl`, `by-source/`, `by-tag/`).
- `log-writer.js` shared formatter; `scripts/import-chrome-logs.js` for storage exports.
- `[LazyFrog:PageReload]` persisted history (`lazyfrogPageReloadLog`).
- Mission dashboard pagination and level-range sort in options.
- Console logging toggle in settings (default off).

## Fixed

- Wrongful page reload after Start (permalink slug stripping).
- Modal closing due to keepalive `visibilitychange` pulses.
- Stuck inn / deleted-post / no-iframe missions.
- `mc__btn-inn` vs `mc__btn-start` preview button handling.

## Changed

- `pageWorldKeepAlive.js` focus pulse interval 15s (was 3s visibility events).
- Docs reorganized under `docs/architecture/`, `docs/plans/`, `docs/changelogs/`.
